### 임시 readme

# <TABA 4기 프로젝트>
크롤링 데이터 기반 맞춤형 채용공고 추천서비스

## 개발 기간
2023년 9월 ~ 2023년 12월

## 프로젝트 소개
잡코리아, 원티트 등의 우리나라 채용공고 사이트에서 데이터들을 크롤링 하여 자소서 맞춤 서비스.
사용자는 학력, 경력, 선호하는 직군, 자기소개서를 입력하면 ai가 분석해 현재 채용공고 중 합격할 확률이 높은 순으로 5개의 기업을 보여줍니다.

### 프로젝트 내 맡은 역할
Front-End

### 개발 환경
React

### 사용 기술
React, Tailwind CSS, React-Redux

로그인 페이지에서 로그인을 시도한 순간 입력학 id(username)을 state로 상태를 가둬서 db에 저장되어 있는 경우에만 로그인 상태 유지(세션이나 토큰 적용 x)

### 프로젝트 느낀점
프로젝트 멤버는 총 5명으로 프론트를 단독으로 담당하였다.
첫 프로젝트 + 첫 프론트 + 첫 리액트 모든게 처음이였던 프로젝트였기 때문에 매우 미숙하였다.
